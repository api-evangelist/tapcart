## API Reference
- [API  Auth](https://dev.tapcart.com/reference/api-setup-and-auth.md)
- [Create an App Studio Component.](https://dev.tapcart.com/reference/post_client-components.md): Creates a new App Studio Component or updates an existing one if `forceUpdate` is true. Requires write auth.
- [Update an App Studio Component.](https://dev.tapcart.com/reference/put_client-components-componentid.md): Updates an existing app studio component. Requires write auth.
- [Get an App Studio Component by key.](https://dev.tapcart.com/reference/get_client-appid-components-componentkey.md): Retrieves an App Studio Component by its key. Requires write auth.
- [Get all App Studio Components for an app](https://dev.tapcart.com/reference/get_client-appid-components.md): Retrieves all App Studio Components for a specific app, as well as tapcart components, if specified. Requires write auth.
- [Get versions of an App Studio Component](https://dev.tapcart.com/reference/get_client-appid-components-componentkey-versions.md): Retrieves all versions of an App Studio Component by its key. Requires write auth
- [Update the version index of an App Studio Component](https://dev.tapcart.com/reference/put_client-appid-components-componentkey-versions.md): Updates the active version of an App Studio Component by setting its version index. Requires write auth.
- [Create a BlockTemplate.](https://dev.tapcart.com/reference/post_client-blocktemplates.md): Creates a new BlockTemplate. Requires write auth.
- [Update a BlockTemplate.](https://dev.tapcart.com/reference/put_client-blocktemplates-blocktemplateid.md): Updates an existing block template if `forceUpdate` is true. Requires write auth.
- [Update the versionIndex of an existing BlockTemplate.](https://dev.tapcart.com/reference/put_client-appid-blocktemplates-blocktemplateid-versions.md): Updates the `versionIndex` of a specified BlockTemplate by blockTemplateId.
- [Retrieve a BlockTemplate by blockTemplateId.](https://dev.tapcart.com/reference/get_client-appid-blocktemplates-blocktemplateid.md): Retrieves a BlockTemplate along with the specified version based on `versionIndex`. Requires read auth
- [Retrieve a list of all merchant-owned custom block templates based on app id. Requires read auth.](https://dev.tapcart.com/reference/get_client-appid-blocks.md)
- [Update dependencies for a specific app.](https://dev.tapcart.com/reference/post_client-appid-dependencies.md): Updates the dependencies of an app identified by the appId. Requires write auth
- [Get dependencies for a specific app.](https://dev.tapcart.com/reference/get_client-appid-dependencies.md): Retrieves the dependencies of an app identified by the appId.
- [Retrieve layouts for a specific app](https://dev.tapcart.com/reference/get_client-appid-layouts.md): Returns a list of layouts for the specified appId. Requires read auth.
- [Insights API](https://dev.tapcart.com/reference/insights-api.md)
- [Clickstream Webhook](https://dev.tapcart.com/reference/clickstream.md)
- [Mobile Event Webhook](https://dev.tapcart.com/reference/insights-stream-setup-guide.md)
